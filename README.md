# AI Sport Coach — GitHub Pages (กล้องแนวตั้ง)

ต้นแบบเว็บไซต์นวัตกรรมการกีฬา ใช้กล้องแนวตั้ง 9:16 ตรวจจับท่าทางด้วย MediaPipe มีการนับถอยหลังก่อนเริ่ม เลือกเวลาฝึก 30–180 วินาที นับจำนวนครั้ง และแสดงคำแนะนำว่าท่าดีหรือควรปรับ

## เผยแพร่ผ่าน GitHub Pages
1. สร้าง repository ใหม่ที่ https://github.com ชื่อ `ai-sport-coach`
2. อัปโหลด `index.html` ไปไว้ใน root ของ repository
3. เปิด **Settings → Pages**
4. เลือก **Deploy from a branch**, branch `main`, folder `/(root)` แล้วกด Save
5. รอ GitHub สร้างเว็บ แล้วเปิด URL ที่แสดง เช่น `https://ชื่อผู้ใช้.github.io/ai-sport-coach/`

## ทดสอบบนเครื่อง
เปิด Terminal ในโฟลเดอร์ที่มี `index.html` แล้วรัน `python -m http.server 8000` หรือบน Windows ใช้ `py -m http.server 8000` จากนั้นเปิด `http://localhost:8000`

## วิธีใช้
- เลือกท่าออกกำลังกาย
- เลือกเวลาฝึก 30, 60, 90, 120 หรือ 180 วินาที
- เลือกนับถอยหลัง 3, 5 หรือ 10 วินาที
- กดเปิดกล้อง อนุญาตสิทธิ์ และรอเริ่ม
- ปุ่มหยุดการฝึกจะปิดกล้องและบันทึกประวัติเมื่อมีจำนวนครั้ง

## ข้อจำกัด
ต้องเปิดผ่าน HTTPS หรือ localhost และเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด MediaPipe/โมเดล ตัวนับและคะแนนเป็นกติกาต้นแบบเพื่อการศึกษา ผลอาจคลาดเคลื่อนตามมุมกล้อง แสง และการบังร่างกาย ควรทดสอบจริงก่อนรายงานความแม่นยำ


## สรุปผลหลังฝึก
เมื่อจบเซสชัน เว็บไซต์จะแสดงจำนวนครั้ง คะแนนท่าทางและความชัดในการตรวจจับโดยเฉลี่ย พร้อมจุดที่ทำได้ดี จุดที่ควรปรับ และแผนฝึกครั้งถัดไปที่แตกต่างตามท่าที่เลือก ผลเป็นคำแนะนำเบื้องต้นจากเกณฑ์ของต้นแบบ ไม่ใช่การประเมินโดยผู้ฝึกสอนมืออาชีพ
